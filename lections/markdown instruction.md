# Инструкция для работы с MarkDown

## Выделение текста

Чтобы  выделить текст курсивом необходимо обрамить его (*) :

*Курсив*

Или знаком нижнего подчеркивания обрамить (_): _курсив_



Чтобы выделить текст жирным нужно обрамить его (**) :

**Полужирный**

Или с помощью обрамления (__) :

__Полужирный__

Альтернативные способы выделения жирным и курсивом нужно для совмещения

Например может быть выделен курсивным и быть полужирным

__Текст выделен *курсивом* и полужирным__

## Списки

Чтобы выделить ненумерованный список выделите его (*)
Чтобы добавить ненумерованные списки необходимо пункты выделить (+)

* Элемент 1
* Элемент 2
* Элемент 3
+ Элемент 4

Чтобы добавить нумерованные списки необходимо пункты выделить (1.)

1. Элемент 1
2. Элемент 2
3. Элемент 3
