# Повторение изученного на прошлой лекциии


**`git init`** - *инцилизация git*

**`git add`** - *Добавление файла для отслеживания*

**`git commit`** - *создание версии (сохранения)*

**`git diff`** - *Вывести разницу между текущим файлом и последним сохранением (коммитом(версии)) в git*

**`git log`** - *Вывести все комиты (версии)*

**`git checkout <number_commit>`** - *Перейти к какому-то сохранению(версии)*

# Новый материал

**`git branch`** - *Вывести список веток (*) означает в какой ветке мы находимся*

**`git branch < new name_branch>`** - *Создание новой ветки*

**`git checkount <name_branch>`** - *Перейти на другую ветку*

**`_text_`** - *второй способ выделить текст курсивом Markdown*

_text_

**`__text__`** - второй способ выделить текст полужирным Markdown*

__text__

**`_текст с двумя **выделениями**_`** - *два способа выделения необходимо для двойного выделения текста одновременно или для смешанного Markdown*

_текст с двумя **выделениями**_

**`git merge <name_branch>`** - *Для переноса из "черновой ветки" в "чистовую" (объеденение двух веток)*

**`git branch -d <name_branch>`** - *Для удаления ветки, но при условии что ветка уже слита(иначе не сработает) ((**_Рекомендуется_**))

**`git branch -D <name_branch>`** - *Для удаления ветки, в любом случае (обратного пути нет) ((**_НЕ Рекомендуется_**))*
