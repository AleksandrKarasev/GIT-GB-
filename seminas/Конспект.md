# Конспект по семинару

**`git init`**  - *Инцилизация гита*

**`# <пробел>`** - *Создание заголовка первого уровня (MarkDown)*

**`## <пробел>`** - *Создание заголовка второго уровня (MarkDown)*

**`### <пробел>`** - *Создание заголовка третьего уровня (MarkDown)*

**`*Курсив*`** - *Выделить текст курсиом Markdown*

**`**Полужирный**`** - *Выделить текст полужирным Markdown*

**`Пропуск 1 строки "---" пропуск 1 строки`** - *Отделить от основного текста*

**`git add <name_file>`** - *Добавление изменений*

**`git commit -m "message"`** - *Создание версии*

**`![Картинка](<ссылка внешняя>)`** - *Добавление картинки внешней*

**`![Картинка](<ссылка на файл>)`** - *Добавление картинки внутренней с ссылкой на файл*

**`[Имя](ссылка)`** - *Добавление ссылки*

**`git add`** - *Добавление измененной файла*

**`git log`** - *Вывести все версии*

**`> "цитата"`** - *Добавление цитаты*

**`>"Циктата 1" >>"Цитата 2"`** - *Добавление вложенных цитат (максимум 15)*


 **`1. Один`** - *Добавление нумерованного списка*

1. Первый
2. Второй
3. Третий


**`- первый способ`** - *добавление ненумерованного списка первый способ*

- первый 
- второй
- третий


**`* первый способ`** - *добавление ненумерованного списка второй способ*

* первый
* второй
* третий

**`+ первый способ`** - *добавление ненумерованного списка третий способ*

+ первый 
+ второй
+ третий

**`*(-)(+) первый способ`** - *добавление ненумерованного списка смешанный способ*


* первый
- второй
+ третий
