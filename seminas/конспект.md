# Семинар 2

**`git init`** - *Инцилизация git*

**`git add`** - *Добавление в гит файла для отслеживания*

**`git commit -m "message"`** - *Создание сохранения (комита) (версии)*

**`git branch <new name_branch>`** - *Создание ветки*

**`git branch`** - *вывести списка веток*

**`git checkout <name_branch>`** - *переход на другую ветку*

**`git add`** - *добавление в отслеживания измененного файла*

**`git commit -m "message"`** - *сохранение новой версии(комита) (сохранения)*

**`git merge <name_branch>`** - *Объеденение двух веток (слияния)*

**`git log --graph`** - *визуализация комитов (версий) (сохранений)*

**`git branch -d <name_branhc>`** - *Удаление веток*
